# 归档的测试

这些测试对应**已被移除的功能**，所以不再参与回归。

## 为什么移除这些功能

用户要求去掉「提供的材质工具和相关数值」。原因：

**预制工具把材质数值写死了**，模型只会照抄，不会按物体自己判断。
结果就是「所有材质用同一套参数」——整场景看起来是同一种材料，只是颜色不同。

改成：材质也要**先调研、再检索、最后自己写节点树**。

## 各文件对应什么

| 文件 | 原来测什么 | 为什么归档 |
|---|---|---|
| `verify_pbr_tools.mjs` | PBR 工具端到端（搭节点树 / 接贴图包 / 烘焙） | 这些工具已全部删除 |
| `verify_material_variety.mjs` | 12 种纹理类型产生不同结果 | 预制的 12 种纹理类型已删除 |
| `verify_seam_grime.mjs` | 接缝痕迹参数（写实 / 卡通两种模式） | 接缝痕迹的预制实现已删除 |
| `verify_seam_dual_radius.mjs` | 双半径接缝检测 | 同上 |

## 如果以后要恢复这些功能

代码可以从 git 历史或备份里找回。恢复时要注意：

1. 这几个测试依赖的工具名（`make_pbr_node_tree`、`bake_*`、`import_texture_set`）
   要重新加进 MCP 工具表和 `HANDLERS` 注册表
2. 插件侧的门禁名单（`TEXTURE_STAGE_TOOLS` 等）也要同步加回去
3. 接缝功能还依赖 `_mk_seam_mask` / `_apply_seam_grime` 两个 addon 函数

**但恢复前先想清楚**：预制数值表会让模型不去自己判断。
如果只是想省事，不如保留「自己写节点树」的方式，只把模板代码放进上下文当参考。
